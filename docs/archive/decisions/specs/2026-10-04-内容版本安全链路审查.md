# SkillHub 内容文件与版本链路只读审查

- 审查日期：2026-10-04
- 代码基线：88e3bdad
- 范围：Markdown 内容读取/编辑/草稿/本地资源/外部打开；另建 Skill、复用修改与继承；版本命名/比较/回滚；这些操作与安全检查及发现处置的衔接。
- 方式：只读核对冻结原型入口、正式路由、TypeScript facade/生成绑定、Rust 应用域、存储和已有测试定义。没有运行测试，没有执行真实文件、网络或 AI 写操作；本报告不是 Windows/macOS 人工验收。

## 结论

当前正式详情页接入原生 facade，但内容编辑器消费的生产契约没有补齐：自动草稿与静态校验都落到 unavailableMarkdownFacade，覆盖保存和另建保存都在调用 Rust 写命令前失败。编辑模式切换/文件切换也绕过脏内容确认，存在直接丢失用户输入的路径。

Rust 层已有受路径和身份校验保护的内容版本保存、另建 Skill、版本差异查询和当前版本切换；这些接口“存在”不代表端到端流程完成。另建流程没有记录产品已确认的“复用修改”来源和继承选择。回滚预览把所有部署关系硬编码为受影响、未固定并将重新检查，提交只切版本指针；DB 当前版本、可见目录、检查结果和页面缓存没有形成同一套可核验状态。主要风险是保存不可用、输入丢失和“已恢复/已检查”与真实版本不一致。

## 已有保护与目前可确认完成的部分

- 内容保存入口有 1 MiB 限制、expected identity 防并发覆盖，并限制相对 .md 文件路径（crates/skillhub-application/src/lib.rs:5261-5308,11603-11628）；Rust 保存应用用例验证 stale identity 冲突（crates/skillhub-application/tests/facade.rs:4134-4199）。这证明路径/身份边界与应用写命令存在，不证明生产编辑 UI 能调用成功。
- Markdown 外链只允许 http/https，屏蔽协议相对/非 http scheme/越界路径（apps/desktop/src/features/markdown/sanitize.ts:7-65）；原始 HTML 不作为可执行 DOM 渲染，远程图片有独立控制，已有单元测试覆盖不安全输入（MarkdownRenderer.tsx:196-200、MarkdownRenderer.test.tsx:89-101）。外链原生打开 command 已接通（nativeApi.ts:81-91）。
