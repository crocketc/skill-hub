## 原始结论与使用方式

- 当前已形成可测试的基础闭环：首次初始化、扫描后批量导入引导、本地目录选择、导入、单 Skill 部署/解除部署、单个删除和批量强制删除、主题选择、备份与数据保护入口等。
- 仍有 **7 个完整 P0 核心缺口**、**1 个部分完成的 P0**、**8 个 P1 管理深度缺口**和 **2 个 P2 体验缺口**。主要问题不再是“页面不存在”，而是管理页缺少关键写操作，以及部分页面的 UI 仍只是摘要展示。
- 本清单只记录尚未完成项。已在本分支完成的初始化批量来源、扩展路径隐藏、导入冲突决策、目录选择器、集中库可见 `skills` 目录、默认部署策略、窄窗口概览布局、主题和安全批量删除，不重复列为缺陷。
- 优先级：P0 = 会阻断核心管理闭环或造成误导；P1 = 当前页面与已确认交互范围有明显差距；P2 = 增强效率、信息完整性或可用性。

## 二、建议的开发顺序

1. **P0 读模型与入口补全**：FE-09、FE-13、FE-16，以及 FE-08 剩余详情读模型。FE-03 与 FE-08 列表读模型已完成；后续先补真实状态与入口，再增加写操作；避免继续在静态摘要上堆按钮。
2. **P0 核心闭环**：FE-01、FE-07、FE-10。完成“选择集中库/恢复 → 发现/导入 → 管理 Agent/项目 → 多目标部署”的用户路径。
3. **P1 管理深度**：FE-05、FE-06、FE-11、FE-12、FE-14、FE-15。按“详情、更新、安全、运维、导出”补全可追溯性。
4. **P2 效率与体验**：FE-02、FE-04、FE-17、FE-18。完成下钻、视图个性化、缩放与键盘验收。

## 三、文档基线处理

`发布版本需求差异审查-2026-09-02.md` 的审查对象是 `v0.1.0` / `main@3027ac1`，其中“Agent、项目、设置、待处理、初始化均未接入”等结论已经与当前分支不符。它保留历史价值，但不应作为后续开发输入；已移至 `docs/development/archive/`，由本清单替代其“当前前端差异”用途。

公开维护的 `docs/release-checklist.md` 不在本次归档范围：它仍是发布候选的质量与人工验收清单，只需在准备正式发布时更新候选提交和最新测试证据。
