## Git 事故预案

历史上两次出现 ref 丢失与 pack 损坏：commit 后立即 rev-parse 校验；损坏时 `git fetch origin` 恢复对象，用 `git rev-parse` 完整 40 位 SHA 写回 `.git/refs/heads/<branch>` 与 `.git/refs/remotes/origin/<branch>`（不要从截断输出复制）。
