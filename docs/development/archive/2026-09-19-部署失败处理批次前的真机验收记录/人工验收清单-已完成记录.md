#### GUI 取证通道（本轮建立，后续真机项可直接复用）

无 GUI 操作信道时，真实桌面仍可被驱动，前提如下：

1. **宿主上 Chromium 的 GPU 进程被沙箱杀死**（阻塞现象：窗口全白、页面停在 `about:blank`、应用 bundle 已内嵌且资源全 200）。原始证据在 `chrome_debug.log`：`ERROR:gpu_process_host.cc:1114] GPU process exited unexpectedly: exit_code=1` 连续 9 次后 `FATAL:gpu_data_manager_impl_private.cc:436] GPU process isn't usable. Goodbye.`。**这是宿主环境问题，不是产品缺陷**（同宿主上应用自身逻辑正常、DB 正常、IPC 正常）。
2. **解法**：`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--no-sandbox --remote-debugging-port=<port> --remote-allow-origins=*`。加 `--no-sandbox` 后 GPU 进程正常、页面渲染、且**路由切换时浏览器进程保持响应**（实测连续 6 次心跳稳定）。
3. **不要用 `--in-process-gpu` 绕过**：页面能出来，但点进 `/relationships` 后承载 CDP 的浏览器进程整体卡死，会得出「应用会挂死」的错误结论。`--disable-gpu`、`--disable-gpu-compositing`、`--use-angle=swiftshader`、`--disable-gpu-sandbox`、`--use-gl=swiftshader`、`--disable-accelerated-2d-canvas` 均**不能**让页面渲染。
4. **窗口真实尺寸**：`Browser.getWindowForTarget` **必须带 `targetId`**（不带会返回 `No web contents in the target`），再用 `Browser.setWindowBounds`；实测可把真实 OS 窗口改成 800×600。
5. **不要用 CDP 的 `Page.navigate` 进深链**：整页导航后是新文档、资源全部 200，但应用 bundle 不执行（`#root` 为空、零异常、零 console）。**必须走应用自身导航**（点击 `<a href>`，或 `history.pushState` + `popstate`）。
6. 仍为自动化的边界：以上只提供渲染层几何与文案证据，**主观观感仍需人工确认**；本通道也不替代 macOS 侧验收。

#### 本轮顺带发现的缺陷（非发布阻塞，建议发布前修）

`tauri.conf.json` 的 CSP 写作 `"default-src 'self'; script-src 'self'"`，**没有显式 `connect-src`**，因此 `connect-src` 回落到 `default-src 'self'`，把 Tauri 的 IPC 自定义协议挡在门外。每次启动都稳定复现两条控制台错误：

```
Connecting to 'http://ipc.localhost/query_application' violates the following Content Security Policy
  directive: "default-src 'self'". Note that 'connect-src' was not explicitly set, so 'default-src' is
  used as a fallback. The action has been blocked.
Fetch API cannot load http://ipc.localhost/query_application. Refused to connect because it violates
  the document's Content Security Policy.
console.warning: IPC custom protocol failed, Tauri will now use the postMessage interface instead
```

后果：IPC 每次启动都先失败一次再回退到 postMessage（功能可用，但多一次失败往返、控制台常驻噪音、且丢弃了自定义协议在大载荷上的优势）。Tauri 官方 CSP 文档给出的参考值明确包含 `"connect-src": "ipc: http://ipc.localhost"`。

**修法（一行，`apps/desktop/src-tauri/tauri.conf.json` 第 25 行）**：

```json
// 原值
"csp": "default-src 'self'; script-src 'self'"
// 现值
"csp": "default-src 'self'; script-src 'self'; connect-src 'self' ipc: http://ipc.localhost"
```

`ipc:` 覆盖 macOS/Linux 的 `ipc://localhost`，`http://ipc.localhost` 覆盖 Windows/Android；`'self'` 保留既有同源请求；`script-src`/`default-src` 仍为 `'self'`，安全档位未放宽。
