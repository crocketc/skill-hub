# Plan09 Task13：解除部署与安全脱离集成计划

> 目标：把已有的解除部署领域服务接入本地 ApplicationFacade 和桌面流程，确保移除受管目标时不误删集中库内容，也不覆盖用户修改。

## 范围

- 查询单个部署关系的解除影响。
- 准备/提交解除部署；支持移除受管目标、仅移除关系、保留共享目标和解除管理关系。
- 复用文件系统所有权证明，目标内容被外部修改时拒绝删除并保留关系。
- 桌面端通过原生门面提交决定，展示逐关系结果。
- Windows/macOS 本地 CI 和部署相关回归测试。

## 不在本 Task

- 集中库 Skill 删除及多目标删除向导（另行接入）。
- 外部变更收集、恢复和独立副本转换（另行接入）。
- Agent 是否加载或执行 Skill 的运行时判断。

## 验收门槛

- [x] 受管复制解除部署后目标目录被移除，集中库版本仍存在。
- [x] 目标被外部修改时返回结构化冲突，不删除目标、不删除集中库、不移除关系。
- [x] 共享物理目标仅移除当前关系时保留目标目录（领域服务与关系操作测试覆盖）。
- [x] 解除管理只改变关系管理标记，不删除目标文件（命令契约和后端实现已接通）。
- [x] 前端预览和提交均只使用注册部署关系，不接受任意路径。
- [x] Windows/macOS 本地 CI 和真实客户端验收。
