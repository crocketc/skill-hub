# Plan 09 Task21：桌面删除门面与影响对话框接线

## 目标

让桌面端能够通过冻结的 ApplicationFacade 契约读取 Skill 删除影响，并提交每条部署关系的明确处理决定；不改变集中库删除规则，不接入备份或卸载流程。

## 任务拆分

### Task21.1 原生删除门面

- 在桌面 removal native facade 中提供删除影响查询和删除提交方法。
- 将前端删除选项映射到 Rust `RemovalDecision`，拒绝未知选项和错误结果类型。
- 用契约测试固定请求 payload、准备操作 ID 和提交结果。

### Task21.2 删除影响对话框

- 保留每条部署关系必须选择处理方式的门禁。
- 将对话框选项映射为集中库删除支持的领域决策，并展示集中库删除结果。
- 对空部署关系允许直接确认；对依赖项目显示提示但不自动级联修改。

### Task21.3 双平台验证与文档

- Windows 运行定向前端测试、类型检查、Lint、生产构建和完整本地 CI。
- 更新 Task 报告与当前开发状态。
- macOS 只读拉取同一提交，运行专项测试和完整本地 CI。
