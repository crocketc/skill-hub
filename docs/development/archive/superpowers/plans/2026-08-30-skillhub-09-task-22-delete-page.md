# Plan 09 Task22：技能详情页删除完整闭环

## 目标

将已有删除原生门面和影响对话框接入技能详情页，形成“发起删除 → 读取影响 → 逐项选择 → 提交 → 成功/失败反馈 → 返回技能库”的桌面端闭环。

## 范围

- 只处理集中库 Skill 删除入口及页面状态。
- 复用已冻结的 `PrepareDeleteSkill`、`CommitDeleteSkill`、`RemovalImpact` 和 `RemovalResult` 契约。
- 不新增备份、恢复、导出、卸载或平台专用操作。
- 不自动级联删除项目配置、未知外部文件或用户原始文件。

## 任务拆分

### Task22.1 详情页删除入口与状态模型

- 在技能详情页提供删除入口。
- 删除入口加载影响数据前显示加载和错误状态。
- 删除过程中保留当前 Skill 上下文，防止重复提交。

### Task22.2 影响对话框接入真实门面与结果处理

- 将真实 `RemovalImpact` 映射为对话框展示模型。
- 复用逐部署关系选择门禁，并调用 `nativeRemovalFacade.deleteSkill`。
- 展示成功、取消、失败和可重试状态；成功后返回技能库并刷新列表。

### Task22.3 批次测试、双平台 CI 与文档收口

- Windows 运行批次定向测试、TypeScript、Lint、生产构建和完整本地 CI。
- macOS 在同一提交上只读执行完整本地 CI 和定向测试。
- 更新当前开发状态和 Task 报告。
