## 已完成内容

- `set_current_version`：校验目标版本存在且属于同一 Skill，更新当前指针和便携清单；便携清单失败时恢复旧指针。
- `save_skill_content`：接收受控的 Skill 内容目录，校验非空 `SKILL.md`，捕获不可变版本并切换当前指针；保存便携清单失败时回滚指针并清理本次新建对象。
- 两类命令均返回结构化 `operation_summary`，不修改旧版本内容，不改变部署关系。
- 详情端已提供切换当前版本的类型化原生调用。
