## 已冻结的关键边界

- Windows updater 使用 `.nsis.zip`，macOS updater 使用 `.app.tar.gz`；DMG 仅用于首次安装。
- 应用内流程为“检查 → 准备 → 下载 → 摘要/签名校验 → 安装 → 自动重启”；缺少清单、平台不匹配或校验失败时保留官方发布页备用入口。
- 私钥只从 CI Secret 读取，公钥同时受 Tauri 配置和 Rust 校验器约束；不把任何私钥、API Key 或更新包正文写入仓库。
- `DownloadApplicationUpdate` 需要可验证的当前平台 manifest；前端不复制版本选择、签名判断或资产映射逻辑。
- 测试 facade 不启动真实安装器；桌面层通过注入的 updater 插件执行安装。真实安装行为只能用真实构建资产验收。
- 下载取消事件尚未纳入冻结命令契约，不应在前端伪造“已取消”结果。
