# Plan 09 Task 10：详情页发现项只读展示

## 目标

将当前版本的基础检查和 LLM 检查发现项接入详情页安全区，帮助用户查看具体规则和文件位置，同时不在本 Task 中执行处置、重新检查或内容修改。

## 已完成

- `SkillDetailFacade` 增加按 Skill、版本和检查类型读取结构化发现项的只读方法。
- 原生门面调用 `ListFindings`，映射规则码、严重级别、处置状态、高风险标记和文件路径；不渲染模型生成的自由文本。
- 安全区展示基础检查发现项和 LLM 检查发现项，列表为空时保持简洁，不伪造“通过”或“无问题”结论。
- 详情页仅在摘要存在真实当前版本时加载发现项；没有当前版本时不发起查询。
- Mock 门面和回归测试同步覆盖发现项列表与文件位置展示。

## 验证

- Windows 前端 TypeScript、ESLint、详情页相关测试和生产构建：通过。
- 详情页相关测试：8 个文件、47 项基础测试，加新增发现项用例后全量共 318 项通过。

## 后续

发现项处置、重新检查、结果重算和部署门禁仍需独立命令与联调 Task；本 Task 不允许在 UI 中直接修改发现项状态。
