# SkillHub 人工验收清单

更新时间：2026-09-08
适用分支：`feat/v0.2.0-product-completion`
适用范围：仅验证浏览器自动化不能替代的真实桌面、文件、网络、系统或发布行为。

## 使用规则

1. 只使用临时集中库、临时 Skill、临时 Agent/项目目录；不得删除、恢复或部署个人真实资料。
2. 每项填写“通过 / 失败 / 未验证”。缺少前置条件时填写“未验证”，不臆测结果。
3. 失败记录操作序号、界面文案/错误码、平台、提交、截图或生成文件路径。文件存在只证明写入成功，不证明目标 Agent 已实际加载。
4. 每项完成后，把结论同步到《功能完成度与验收状态矩阵》的 Windows 或 macOS 列。

**前置条件**：未初始化或可安全重新运行初始化向导；准备两个临时目录。

1. 重新运行初始化，选择“新建集中库”，用系统目录选择器选取临时目录。
