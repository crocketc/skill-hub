## 本轮设计决策（产品取舍记录）

1. **来源模型**：搜索结果只生成待确认候选，confirm 仅登记"导入意向"，来源在完成导入后才存在；dismissed 不可撤销（后端无该命令，UI 如实呈现，"撤销忽略"需未来后端能力）。
2. **在线安装**：单 Skill 安装通过 `directory` 参数只取该子目录；解析不出 `/tree/` 目录时保留整仓下载但显示"将导入整仓"警示徽标（不静默、不禁用）。
3. **排除/删除边界**：发现页"排除"=创建忽略规则（可撤销、二次确认），不提供任何磁盘删除入口。
4. **ZCode**：主候选 `~/.agents/skills`；`~/.zcode/skills` 保守保留为 lower_priority_copy（官方文档无法在线核实，且经核验不会造成误报）。
5. **概览 IA**：deployments 指标保留"部署关系计数"措辞（deployed_count 是 skill×target 关系数，改称 Skill 数会失真），钻取用 `/library?deployment=deployed` 区分目的。
6. **组合身份**：组合以 name 为身份（既有 schema），本轮最小修复=重命名命令+防重名+歧义冲突；"按 id 重构组合身份""一键消歧"为未来后端任务。
7. **项目页诚实缺省**：无删除/注销命令→无入口；无健康数据源→四态访问徽章；list() 无 Skill 关联数据→不显示数量（拒绝 N+1 伪造）。
8. **移除语义**：四种对象（取消部署/移除标签/移除部署关系/删除库中 Skill）各自唯一名称+影响预览+恢复说明；"保留目标文件"选项文案与后端 `remove_relation` 行为逐字对齐（审查修复轮纠正过一次反义文案）。
9. **页面节奏**：`--page-gap` 统一页头↔正文间距，PageFrame 双重内边距删除（外留白 40→20px）；如真机觉得过紧应调 token，不恢复双重内缩。
10. **CJK 审计豁免**：`features/projects/ProjectsPreview.tsx` fixture 中文按 T0 先例登记豁免（DEV-only、生产构建消除）。
