## 本轮：DEV-110 Agent 卡片角色、能力与布局统一（2026-09-30）

**已完成（实现）**：

- Agent 目录角色明确为用户、工作区和内置；`scope=project` 的 Agent 发现目标映射为工作区，单独注册的 Project 实体继续使用项目模型并从 Agent 卡片排除。
- 共享目录实体标志与 Agent 是否支持共享目录的能力分离；共享目录能力保留到 Agent 成员事实。
- 同一物理共享目录按物理身份归并，不会因 Agent 用户/工作区角色差异生成重复实体。
- Agents、初始化/重新扫描、发现工作台、单项部署和批量部署卡片固定为统一高度与信息区域；角色使用有色文字徽标；部署状态在平台类型左侧；共享品牌最多显示四个并以“+N”收纳。
- 底栏能力收敛为复制和链接两个无底色图标，绿色表示支持、红色表示不支持，悬浮/无障碍文案明确说明能力；内置目录不提供写入派发。
- 同步卡片模型设计文档、自动化说明、人工验收流程和完成矩阵。

**仍需**：用户使用本轮新建的 Windows EXE 完成流程 L，并按验收表记录实际截图/结果；在记录真实操作前保持“人工待验收”。macOS 需之后独立构建复验。此前边界一/二/三及其结果见下文历史记录与自动化说明。
