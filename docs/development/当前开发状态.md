## 重要技术边界

- `crates/skillhub-core` 不依赖桌面 UI。
- `apps/desktop/src-tauri` 负责本地后端桥接；当前 Task 4 的应用 Facade 执行和原生文件选择器接入仍未完成。
- `apps/desktop/src/api/bindings.ts` 和 Rust bindings 必须由 Specta 生成，不能手工维护接口副本。
- `PathGrant` 只传 opaque grant ID；实际目录必须由 `PathGrantResolver` 解析。
- Windows 路径比较按不区分大小写处理；macOS 保留观察到的大小写。
- 发现和兼容性模块只记录文件与目录事实，不声称 Skill 一定能被 Agent 执行。
- 基础安全检查必须是确定性的；LLM 检查只能作为独立增强。

## 恢复开发时的入口

1. 阅读根目录 `AGENTS.md`。
2. 阅读 `docs/需求文档.md`、`docs/产品与交互设计.md`、`docs/技术架构设计.md` 和对应实施计划。
3. 阅读本文和 `docs/development/任务交接模板.md`。
4. 查看 `git status`、`git log`，确认主分支基线。
5. 为下一个 Task 创建独立 worktree 和分支。
6. 先写失败测试，再实现最小行为。
7. 完成任务测试、整仓测试、格式、Clippy、bindings 漂移检查和 `git diff --check`。
8. 由独立 Agent 复审后再合并到 `main`。
