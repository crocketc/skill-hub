## 重要技术边界

- `crates/skillhub-core` 不依赖桌面 UI。
- `apps/desktop/src-tauri` 负责本地后端桥接；真实 ApplicationFacade 执行和原生文件选择器接入仍需后续 Task 完成。
- `apps/desktop/src/api/bindings.ts` 和 Rust bindings 必须由 Specta 生成，不能手工维护接口副本。
- `PathGrant` 只传 opaque grant ID；实际目录必须由 `PathGrantResolver` 解析。
- Windows 路径比较按不区分大小写处理；macOS 保留观察到的大小写。
- 发现和兼容性模块只记录文件与目录事实，不声称 Skill 一定能被 Agent 执行。
- 基础安全检查必须是确定性的；LLM 检查只能作为独立增强。
