# SkillHub 缩放与键盘验收矩阵

创建时间：2026-09-06（Q16 收尾项）  
适用分支：`feat/v0.2.0-product-completion`  
使用方式：在 Windows 显示缩放 100% / 125% / 150% 下分别执行同一路径，把每个单元格记为"通过 / 失败 / 未验证"；失败需附截图与窗口尺寸。

## 一、范围与记录规则

- 覆盖页面：概览、技能库、技能详情、发现、Agent 列表、Agent 详情、项目列表、项目详情、待处理、操作记录（恢复）、数据保护、设置。
- 每页在三个缩放档位下检查同一组维度：
  1. **布局**：主内容按栏宽收缩或换行，不出现横向溢出、控件塌陷或文字截断（省略号除外，需悬浮可见全文）。
  2. **滚动**：内容超出视口时出现纵向滚动条；不出现整页横向滚动（表格/矩阵等明确横向滚动的区域除外）。
  3. **交互**：按钮/输入/下拉在当前缩放下可点、可聚焦，热区高度 ≥ 约 24px 视觉等效。
  4. **键盘**：Tab 顺序符合视觉顺序；抽屉/对话框可 Esc 关闭；焦点回到触发元素。
  5. **诚实状态**：加载/空态/错误提示在窄空间下仍完整可读，不因缩放被裁剪。

## 三、每格验收动作（同一套）

1. 打开该页面，逐档缩放（Ctrl+滚轮或系统设置），确认"布局/滚动"两条。
2. 用键盘走完该页主路径（Tab/Shift+Tab/Enter/Esc），确认"键盘"条。
3. 触发一次加载/空态/错误（如断网、空搜索结果），确认提示完整可读。
4. 结果记入回传格式；失败必须写明缩放档位、窗口尺寸与错误文案。

## 四、特别关注点（历史问题回归）

- 100% 下多页曾出现"内容超一屏但无滚动条"（已修复：主内容区 overflow-y auto）——重点回归。
- 概览窄窗口曾塌陷为单列——重点回归 125%/150%。
- 恢复页双页签、技能库三视图切换控件在 150% 下不得换行错位。

## 五、回传格式

```text
提交：<short-sha>
缩放：100% / 125% / 150%
每页结果：<页面名>：100% 通过；125% <通过/失败+说明>；150% <…>
键盘流程：每页 Tab/Esc 是否符合预期
失败清单：页面 + 档位 + 现象 + 截图
```
