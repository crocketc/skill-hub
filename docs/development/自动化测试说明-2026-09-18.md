### Windows 能力探测的真机边界（只能真机观察）

在本机非管理员账号上，`std::os::windows::fs::symlink_dir(target, link)` **返回 `Ok(())` 却没有创建任何东西**：紧随其后的 `symlink_metadata(link)` 报 `os error 2（系统找不到指定的文件）`。产品的 `probe_symlink` 会复核创建结果是否真的成为 reparse point，因此正确判定 `symlink = false` 并回退目录联接；若采信 `CreateSymbolicLink` 的返回值，转换会在用户目录里留下一个空目录（`filesystem.rs` 注释中描述的「报告成功但未落地」正是这一情形）。该行为在 macOS 上无法复现，属 Windows 真机独有证据。
