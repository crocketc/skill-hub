### 产出用于真机验收的 release 产物（2026-09-18 实测口径，两条坑）

1. **必须用 `tauri build`，不能只用 `cargo build --release`。** `tauri build --no-bundle -v` 原样打印出它实际执行的命令是 `cargo build --bins --features tauri/custom-protocol --release`。缺 `tauri/custom-protocol` 时产出的 exe **不内嵌/不伺服前端**：窗口能开，但页面停在 `chrome-error://chromewebdata/`、`document.querySelectorAll('main').length === 0`。本轮实测对照——坏产物 26,348,544 字节 / 正常产物 28,176,384 字节。**任何真机 UI 验收前都应先确认页面 URL 是 `http://tauri.localhost/` 且 `main=1`**，否则后续所有几何结论都是无效的。
2. **`tauri build` 可能卡在 `beforeBuildCommand` 不返回。** 本机实测一次 `pnpm --dir apps/desktop tauri build --no-bundle`：前端步骤已写出 `dist/assets`，但随后 **11 分 18 秒内无 cargo 进程、日志无新增**，最终只能手动终止（`tauri build -v --config` 覆盖后同一仓库 1 分钟内正常完成）。规避法是分两步：

   ```bash
   pnpm --dir apps/desktop build
   pnpm --dir apps/desktop tauri build --no-bundle --config '{"build":{"beforeBuildCommand":"echo frontend-already-built"}}'
   ```

   注意前端产物哈希不变时（例如只改 `tauri.conf.json`）也要**重跑一次 `tauri build`**：CSP、图标、窗口配置都是编译期内嵌的。
