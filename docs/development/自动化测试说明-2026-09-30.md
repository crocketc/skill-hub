## 运行注意事项

- **E2E 必须用 `pnpm test:e2e`**（根目录脚本带 `--config=tests/e2e/playwright.config.ts`）。直接 `npx playwright test` 不加载 baseURL，会大面积报「Cannot navigate to invalid URL」——是调用方式错误，不是产品缺陷。
- 单测需在 `apps/desktop` 目录下运行 vitest；从仓库根会解析到无 jsdom 配置的 vitest。
- 全量 E2E 基线 404/404 为 2026-09-25；本轮定向运行 agents/deployment 相关 61 项。

## 不能替代人工的边界

- 自动化不覆盖：真实用户目录与 Agent 文件保护、真实权限/只读目录、Windows 目录联接与 macOS 符号链接的真实落盘、跨卷行为、真实窗口/主题视觉、长路径与批量耗时、通知中心人工可读性。
- 自定义 Agent 的真实登记（原生文件选择器授权）、真实目录替换后的身份变化拦截、部署/解除落盘，均属流程 L 真机范围。
- E2E 使用 DEV 预览路由与 mock 门面，只能证明前端契约与几何，不能证明原生 IPC 与数据库的真实往返。
- DEV-101 的真实进程崩溃时序无法在自动化中稳定制造；闸门行为按流程 I 真机验收。
