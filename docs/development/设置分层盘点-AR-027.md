## 3. 目标分层（两层结构 + 页面内分区）

```
设置（SettingsPage）
├── 1 通用：语言 / 主题 / 密度（原 General + View 合并目标）
├── 2 数据保护（父模块，入口卡 → /settings/data-protection 全功能页）
│     ├── 备份（位置/保留天数/滚动备份）
│     ├── 恢复（从备份恢复）
│     ├── 导出（标准导出，版本范围/输出目录）
│     ├── 退出管理（卸载前处理）
│     └── 恢复点说明（自动管理）
├── 3 网络与 AI：联网总开关 / LLM 提供方 / 数据发送范围
├── 4 自动化：逐 Skill / 批量 / 全局自动检查
├── 5 技能库维护：库路径与健康检查 / 忽略规则
└── 6 应用更新
```

设计原则（源自需求 §6）：
- 数据保护是用户资产安全的父概念，备份只是其子能力——层级必须体现这一关系。
- 不设“普通/开发者”双模式；所有卡片同一层级平铺但按分区标题分组。
- 每个能力必须可从设置页到达其功能页（数据保护页、技能库卡内操作）。
