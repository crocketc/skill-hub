# Windows 早期版本安装说明

SkillHub 早期 Windows 构建使用 NSIS 当前用户安装模式，不要求管理员权限，也不会修改系统范围的安装目录。由于构建尚未配置受信任的代码签名证书，Windows SmartScreen 可能显示“Windows 已保护你的电脑”提示；这不是 SkillHub 绕过系统安全策略的理由。

## 安全安装路径

1. 只从项目的官方 GitHub Release 页面下载对应架构的 `.exe`。
2. 在 Release 页面核对同一版本的 `SHA256SUMS.txt`，再使用系统属性或可信的校验工具核对文件摘要。
3. 如果文件来源、版本或摘要不一致，不要运行安装器，并通过项目渠道反馈。
4. 只有在确认来源和摘要后，按 Windows 提示选择继续；如果组织策略禁止未签名应用，请联系管理员或等待受信任签名版本。

安装器默认只为当前 Windows 用户安装。卸载、Skill 集中库和用户配置是独立的数据操作，卸载不会自动删除用户 Skill。

## 当前边界

- 早期版本不提供静默自动更新；应用内更新检查只打开官方 Release 页面。
- 文档不要求关闭 SmartScreen、修改执行策略或运行管理员命令。
- 后续配置受信任发布者后，需要重新验证安装包、签名、更新策略和发布清单，不能仅替换一个证书配置。
