# 产品规范索引

本目录是版本化的产品规范入口，不存用户真实数据或个人验收素材。AGENTS.md 只保留通用开发约束并路由到这里。规则拆分不改变用户已确认的产品决策，不等于相关功能已经实现或通过验收。

## 维护和优先级

- 已确认的产品定位/展示/入口规则在本目录维护；具体动作和持久化边界在[业务决策模型](业务决策模型.md)维护。不能让讨论稿/已替代建议覆盖明确确认的规则。
- 界面按钮位置与样式已由用户确认；抽屉与完整详情分工明确，统一样式和流程不意味着两处内容完全相同。
- 模型文件的权威内容自包含于[业务决策模型](业务决策模型.md)；历史讨论及未裁决细节归档于 docs/archive/（见 [docs 文档地图](../README.md)），只用于追溯，实施必须以本目录已确认规则为准；发现实质冲突先由产品负责人收口，不自行择一。
- 同一规则不要在AGENTS.md反复追加全文；规范变更同步关联模型/计划的引用与当前状态，保留历史证据。
- 当前开发/测试/真机状态仍只由 `docs/development/` 的四份当前文档汇总；产品规范和浏览器预览不能充当交付或真机通过记录。
