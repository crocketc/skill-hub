# Plan09 Task14：外部部署变化联调计划

> 目标：把已完成的外部变化领域服务接入本地 ApplicationFacade 和桌面端，确保外部修改/缺失目标必须经过确定性观察和用户明确选择。

## 范围

- 查询单个部署关系的外部变化计划。
- 接入收集为新版本、恢复当前版本、保留独立副本和忽略变化四类显式操作。
- 复用注册目标、物理身份和目录树哈希；目标缺失或被替换时不自动重建、不覆盖未知目标。
- 更新部署关系的版本/哈希事实，或移除管理标记；保留操作结果可追踪。
- 桌面端通过原生门面调用类型化查询和命令。

## 不在本 Task

- Agent 运行时调用记录和执行能力判断。
- 集中库删除、备份、卸载和独立副本再次导入。
- 自动恢复、自动收集或绕过用户确认的批处理。

## 验收门槛

- [x] 未变化目标不允许执行外部变化处理动作。
- [x] 修改目标可查询明确的允许动作；收集生成新版本并更新关系事实。
- [x] 缺失目标不自动创建；恢复、保留独立副本和忽略均按显式命令处理。
- [x] 目标身份变化或路径不在注册目标中时返回结构化错误并保留原关系。
- [x] Windows/macOS 本地 CI 和专项测试通过。
