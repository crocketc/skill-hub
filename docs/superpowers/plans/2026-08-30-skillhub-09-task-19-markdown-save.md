# Plan09 Task19：Markdown 草稿原生保存

## 目标

让详情页轻量 Markdown 编辑器把内存草稿安全保存为新的不可变 Skill 版本，同时保留外部修改冲突检测和版本回滚能力。

## 任务拆分

### Task19.1 冻结命令与结果契约

- 新增独立的 `SaveMarkdownContent` 命令，不改变既有 `SaveSkillContent` 目录源契约。
- 请求包含 Skill、相对 Markdown 路径、草稿文本和读取时的内容身份。
- 结果返回新版本 ID、保存文件路径和新内容身份，供编辑器刷新查询缓存。
- 路径必须是 Skill 版本清单中的 Markdown 文件，不接受绝对路径或目录穿越。

### Task19.2 实现安全写入

- 读取当前版本并校验内容身份，发生外部修改时拒绝写入。
- 在临时工作区复制当前版本，只替换目标 Markdown 文件，再捕获新版本。
- 更新当前版本和便携清单；任一步失败都恢复旧指针并清理临时对象。
- 仅受管 Skill 可编辑，旧版本保持不可变。

### Task19.3 双平台验证与文档

- Windows/macOS 运行本地 CI、冲突和回滚专项测试。
- 更新生产 Markdown 门面、进度文档和 Task 报告。
