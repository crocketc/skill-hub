# Plan09 Task20：集中库 Skill 删除闭环

## 目标

删除集中库 Skill 前先展示影响范围，并要求用户为每个活动部署关系作出明确决定；确认后安全移除管理数据和版本对象，保留用户原始文件，失败时可恢复。

## 任务拆分

### Task20.1 删除影响检查与显式决定接线

- 接通 `PrepareDeleteSkill` 与 `CommitDeleteSkill` 到 ApplicationFacade。
- 影响结果包含 Skill、活动部署关系和依赖项目；没有影响时也返回可确认的空列表。
- 缺少决定、关系发生变化或取消时拒绝提交，不删除任何集中库数据。
- 集中库删除不接受 `DetachManagement` 决定；该决定用于保留集中库的独立解除管理操作，删除时应选择保留目标并移除关系。

### Task20.2 集中库 Skill 与版本安全删除

- 处理删除目标和部署关系后，再删除目录清单、Skill 元数据和不再被其他版本引用的对象。
- 不删除 Agent/项目中的用户原文件；共享目标和独立副本按用户决定保留。
- 覆盖权限失败、对象清理失败和可恢复回滚。

### Task20.3 双平台验证与文档

- Windows/macOS 运行本地 CI、删除影响和回滚专项测试。
- 更新开发状态与 Task 报告。
