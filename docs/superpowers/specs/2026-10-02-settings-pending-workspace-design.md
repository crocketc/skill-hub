## DEV-117：按处理归属组织待处理

```
紧凑页头与真实计数
搜索 / 分类 / 保存视图 / 历史
软件建议（可安全直接处理）
技能复核 / 关系工作台 / Agent / 恢复（摘要与业务入口）
```

- 软件建议/初始化：AI、备份、导入使用现有确认、暂缓、精确忽略及设置/发现入口。
- 技能复核：安全、基础检查、试用、更新按目的聚合；呈现真实事项数、涉及对象和最高风险，处理转到技能安全、版本、技能库等现有工作流。
- 关系冲突/治理/导入后续：每个工作台摘要入口，不在此逐条复制关系明细和决策 UI。
- 恢复：进入操作记录与恢复工作台，不提供待处理页即时恢复。
- Agent 兼容性：同目标的复制/链接未确认事项归并，使用统一 logo 与展示类型；反馈在 Agent 详情完成，共享目录继续为独立实体。
- 默认紧凑分类列表，可展开必要轻量明细和单项精准深链。高风险原因常显，内部标识不进入正文或无障碍名称。
- 两种数量分别说明：底层待处理事项数与聚合处理入口/对象数；推荐事项另计。保持原生事实、忽略规则、来源不可用提示和概览计数来源，不靠删后端事项制造清爽界面。
- 安全批量暂缓/忽略映射到精确事项；关系、恢复、安全高风险和兼容性不得借组选择进入批量忽略。保留部分选择、逐项结果、首错停止、失败刷新与历史撤销。
- 保留原 kind/subject 深链、保存视图、7/30 天暂缓、刷新与回到前台核对。聚合跳转只使用目标实际支持的过滤和路由。
- 检查真实试用标签/到期与 native convert 行为、去重、部分失败和持久化边界。确认实际问题后最小修复；若更改契约，必须生成绑定，不手写重复接口。

已确认适配器缺陷：原 `nativePendingFacade.convert` 使用 `set_lifecycle Normal`，不会清理 `trial_due` 与 `temporary_trial`，事项仍可能重新出现。改用既有 `set_trial { due: null }` 原子清理试用信息，保持生命周期与部署不变；以失败契约测试覆盖，无需新增 Rust 契约或手写绑定。

兼容性归并复用同次 Agent 目录投影中的共享目录标志与文件系统身份，不按品牌或字符串路径猜物理目录。仅补充前端本地展示元数据，保留后端事实来源与原生决策边界。

跨模块接入由负责人实现：待处理批量安全/更新入口携带 `pendingReview`，技能库校验结构与本地返回地址，通过已有精确匹配查询去除失效 Skill，只预选并聚焦既有批量栏，不自动执行。清除选择后不重新施加预选；准备失败仅显示局部提示，返回入口仍可用。高风险安全发现不进入此批量载荷。
