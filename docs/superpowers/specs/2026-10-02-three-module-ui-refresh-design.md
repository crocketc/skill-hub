# 技能库、快捷抽屉与关系治理增量优化（2026-10-02）

## 产品目标与边界

按 AGENTS.md 的技能全生命周期定位，技能库负责资源检索，快捷抽屉负责单技能摘要与常规操作，关系治理负责去向、影响与处置。用户指定三张参考图并授权产品负责人制定执行方案，三个执行 agent 各用独立分支、worktree，模型为 GPT-6 luna，思考等级 xhigh。

采用参考图的结构、层级和间距，不引入订单、员工、任务等参考图业务。保留现有操作、查询门面、权限、确认、回滚和通知桥；本轮不修改后端契约、生成绑定、全局主题或主导航。使用现有主题 token、字体和共享 presenter。

## DEV-113：技能库列表工作台

- 搜索常驻；筛选入口、导入及次要设置在紧凑工具带中对齐。高级条件清楚分组，保留清除、保存视图、列偏好、密度、标签分组和批量操作。
- 宽窗口搜索与主要操作同排，次要分组/组合入口并入视图工具区；窄窗口按完整操作组换行，避免工具带占据过多列表高度。
- 保存视图呈现为页签，列表采用柔和表头与清晰分隔行。卡片、矩阵及视图切换保持原有功能与用户偏好。
- 表头明确显示未排序、升序和降序；名称、生命周期、Agent 派发数、项目派发数、版本使用真实原生排序能力，排序重置页码并保留筛选。不使用当前页排序冒充全库排序。
- 不从分页数据伪造全库统计、增长率或使用排名。不新增原地更新视图等本轮范围外能力。
- 主要文件：技能库页面、筛选、表格、保存视图、分页和非抽屉范围的 skills.css。

## DEV-114：技能快捷抽屉

- 轻量顶部工具区、突出的名称与状态、标签和值对齐的摘要、便于编辑的用途与备注、次要模块分区；主要操作、高风险摘要和完整详情入口易于找到。
- 保留别名、用途、备注、标签、翻译确认、模块全局显隐与拖拽、恢复默认、三档宽度与拖动记忆、关闭焦点恢复、独立滚动及失败恢复。
- 调用方式保持只读；所有摘要和操作在完整详情页同步可达。使用独立 skillQuickDrawer.css，避免与列表分支共享修改。

## DEV-115：关系治理看板

- 默认状态分栏看板，保留可切换的高密度表格。紧凑顶部工具区保留搜索、所有筛选、历史、选择与批量操作。
- 卡片展示可读技能名称、关系类型、目标、来源、核验/受阻原因和现有操作。每条关系仅进入一栏；分组来自 status/readiness 的真实事实，覆盖可纳入管理、待核验、受阻及已明确关系，不虚构进行中或完成状态。
- 分栏优先级：受阻事实优先，其次待核验与需要关注，再是可纳入管理，最后已明确。来源副本不把固定的内部 readiness 值解释为原副本已转换；展示真实状态与保留决策。次要可读事实允许展开收纳，受阻原因与操作常显。
- 两视图共享操作判定与 presenter，保留来源副本保留/清理、共享影响确认、移除、重校验、准备/提交/回滚、深链与返回状态。
- 列数量描述当前筛选结果。空名称使用可读兜底，内部标识不进入正文或无障碍名称；共享目录维持独立实体语义。
