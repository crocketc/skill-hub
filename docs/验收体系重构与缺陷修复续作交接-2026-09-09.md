## 3. 当前 QA 状态

### QA-002：部分完成

已稳定复现并修复：`LibraryStep.tsx` 在存在 `customLibraryPath` 时禁用“选择其他目录”，导致用户无法恢复。

- 新增失败测试：选择过自定义目录后，原生选择器仍可再次打开。
- 修复：移除错误禁用条件。
- 增加回归：重启失败后可以选择另一路径并重新提交，且不能误报初始化完成。
- 未关闭原因：用户遇到的 `library_root_locked` 还需在 Windows 上复现启动数据库状态和重启链路。已初始化库仍应禁止直接换根目录，不能通过放宽后端保护绕过迁移流程。

### QA-003：自动化修复完成

根因：`ImportWizard.pickLocalDirectory()` 明确执行 `setSelectedSources([])`。

- 失败测试证明：两个已选扫描来源加一个原生选择目录时，只剩最后一个。
- 修复：规范化新目录并追加到当前选择，保留已有来源。
- `ImportWizard.test.tsx` 相关测试通过。

### QA-004：自动化修复完成

### QA-006：实现中

已确认根因：`OverviewPage` 使用启动时静态 `BootstrapSnapshot`；导入成功只失效 Skill 列表查询，导入命令也不会发布 `facts_changed` 事件。

当前实现：

- `BootstrapGate` 提供不卸载应用外壳的 `refreshSnapshot()`。
- `AppShell` 通过 Outlet context（出口上下文）共享 `snapshot` 与刷新动作。
- `DiscoveryRoute` 在存在成功导入结果时，同时刷新 Skill 列表和启动快照。
- `BootstrapGate.test.tsx` 已验证刷新后 Skill 数从 42 变为 43。

仍需完成：增加发现/导入路由集成断言，直接证明成功导入调用刷新、全失败结果不调用刷新；随后再将 QA-006 标记完成。
