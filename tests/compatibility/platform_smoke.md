# 平台兼容性真机验收模板

本文件定义统一的 Agent 文件管理验收用例。它只记录 SkillHub 对目录、文件和部署关系的观察结果，不认证 Agent 是否能成功执行 Skill，也不推断登录、授权、信任或运行时调用次数。

## 证据等级

- `官方资料`：来自对应 Agent 官方文档和明确引用。
- `文件接入已验证`：在指定操作系统上观察到目录、文件变化、部署和解除部署行为。
- `未安装—未进行真实机验证`：本机没有该客户端，不能把 profile 规则当成实测结论。
- `无法判断`：客户端存在，但目录优先级、所有权或变化无法由安全的只读观察确定。

## 每个已安装客户端的用例

记录客户端形态、操作系统、安装方式、客户端数据根目录和测试提交号，然后依次执行：

1. 发现：创建用户级和项目级 Skill，记录真实文件位置。
2. 导入：放入最小合法 Skill、缺少 frontmatter 的 Skill、嵌套目录和同名 Skill，记录扫描结果。
3. 部署：分别验证复制、符号链接和（仅 Windows）Directory Junction；记录是否覆盖非 SkillHub 文件。
4. 可见性：在 Agent UI/CLI 中确认文件出现，但不把可见性等同于可执行性。
5. 外部变化：修改、移动、重命名和删除已部署文件，运行刷新/收集并记录所有权提示。
6. 解除部署：确认只撤销 SkillHub 自己的部署关系，保留用户独立文件。
7. 恢复：在中断或权限不足后验证恢复方案和待处理事项。

每个用例都要记录命令或 UI 操作、观察到的路径/文件事实、结果、异常和证据等级。未执行的用例写明原因，不用“通过”替代。
